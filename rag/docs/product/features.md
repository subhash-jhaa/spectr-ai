# Spectr Features

Spectr provides real-time website analytics and performance monitoring capabilities:

- **Web Analytics Dashboard**: Track total page views, unique visitors, referral sources, top pages, geographic visitor distribution, devices, and browsers.
- **Core Web Vitals Monitoring**: Live tracking of Largest Contentful Paint (LCP), Interaction to Next Paint (INP), and Cumulative Layout Shift (CLS) with P75 aggregation.
- **Real-Time Active Visitors**: Live counter showing active users on site right now.
- **UTM Campaign Tracking**: Inspect marketing traffic by source, medium, and campaign.
- **Ask Spectr AI**: Built-in intelligent conversational assistant capable of querying site data and explaining performance metrics.
- **Privacy-First Architecture**: Zero cookies, anonymized IPs, no cross-site tracking, fully compliant with GDPR and CCPA.
