# About Spectr

Spectr is a privacy-first, cookie-free web analytics and Core Web Vitals monitoring platform. It delivers real-time website performance insights and visitor tracking without intrusive tracking cookies, banner consent requirements, or user data selling.

## Pitch & Purpose
Spectr provides website owners, developers, and product teams with clean, actionable web analytics combined with Google Core Web Vitals metrics in a single unified dashboard.

## Target Audience
Spectr is built for modern web developers, SaaS founders, agency owners, and privacy-conscious businesses who want fast, lightweight analytics without compromising user privacy or violating privacy regulations like GDPR and CCPA.
