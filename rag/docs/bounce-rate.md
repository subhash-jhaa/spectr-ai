# Bounce Rate

Bounce rate is the percentage of total website sessions where a user views only a single page and exits without triggering any further interactions or page views.

## User Experience Impact
Bounce rate indicates user engagement and content relevance. A high bounce rate suggests visitors did not find what they expected, encountered broken elements, or found immediate answers without further navigation.

## Official Threshold Ranges
- **Good**: < 40%
- **Needs Improvement / Average**: 40% – 60%
- **Poor / High**: > 60%

## Spectr Implementation
Spectr calculates bounce rate by dividing single-event sessions by total sessions recorded in the `Event` table for a project over a specified time window.
